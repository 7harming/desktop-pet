# 逗貓棒 設計文件

- 日期：2026-10-01
- 狀態：已和主人逐段確認
- 範圍：桌面上可以拖的逗貓棒，貓咪坐起來用兩隻前手往 5 個方向撲

## 1. 主人的選擇

| 問題 | 選擇 |
|---|---|
| 怎麼玩 | 桌面上放一根逗貓棒，用滑鼠拖著晃，放開就停在原地 |
| 貓咪的反應 | 在動才撲；停下來 5 秒就失去興趣 |
| 從什麼姿勢撲 | 坐著（寵物包的 `alert`／`sit`），撲完回到坐著 |
| 方向 | 5 個：左、左上、正上、右上、右 |
| 樣式 | 彩色羽毛（橘、藍、黃三根羽毛，用線吊在木棒上） |
| 往上撲的空間 | 維持原本的鏡頭：叫影片模型讓前手不要超出畫面上緣（不縮小重拍） |
| 重複 | 每個方向一種版本；剪短到約 1.5–2 秒，每次播放速度隨機 ±10%；太重複再補第二種 |

## 2. 怎麼玩

- **拿出來**：右鍵貓咪「拿出逗貓棒」，系統列選單和面板也有；出現在那隻貓斜上方。拿出來後選單變成「收起逗貓棒」。關掉程式就收起，不記位置。
- **拖著晃**：按住棒子或羽毛拖動；羽毛用線吊著，擺錘物理，跟著甩、慢慢停下。只有棒子、線、羽毛抓得到，其他透明處點得穿。
- **貓咪**（每隻各自判斷，每 50 ms 一次）：
  - 羽毛在動（速度超過一個門檻）而且離頭在「注意範圍」內（約一個身長）：貓咪坐起來盯著（`alert` 姿勢，自動行動暫停）。
  - 羽毛在「搆得到的範圍」內（頭的周圍，約半個身長）而且在動：往羽毛所在的方向撲；撲完回坐姿，羽毛還在動就再撲（兩次之間至少 0.4 秒）。
  - 方向依羽毛相對於頭的角度分 5 區：左（低於頭）、左上、正上、右上、右。
  - 羽毛停下來 5 秒（或離開注意範圍）：失去興趣，回到平常的行動。
  - （0.7.1，主人試玩後）換方向要快：撲剪到約 1.1 秒；新的方向在上一下播過一半（手往下放）時就可以接上，同一個方向則等上一下播完。羽毛在附近動時，主程式每次都重送「盯著／撲」，所以一開始在忙（例如正好在打鬧）的貓，一有空就會加入。逗貓棒拿出來時，牠們不會自己開始打鬧。
- **不理逗貓棒**：睡著（主人離開電腦）、提醒事項到點坐著提醒、打鬧中、走進走出中、被拖曳中。

## 3. 影片

- 每隻貓 5 支（`swat_left`、`swat_up_left`、`swat_up`、`swat_up_right`、`swat_right`），共 10 支。
- Veo 3.1 lite 首尾幀（first = last = 坐著的定格，跟 `idle_sit` 同一張，所以接得起來），4 秒，720p，綠幕，之後去背轉成 VP9 透明 WebM。
- 提示：兩隻前手一起撲、肉球、爪子收著、嘴巴閉著；前手不超出畫面上緣、後腳不離地；方向用「畫面的左邊／右邊」說。
- 後製（spike `wand2_cut.py`）：只留貓的輪廓跟坐姿差超過最大變化 10% 的部分（前後各多 2 格）；超過 26 格（約 1.1 秒）就平均抽格加速（0.7.0 是 44 格、1.8 秒）；Veo 在幾格裡自己畫了吊在線上的小球（畫面最上緣），最上面 140 列裡跟貓沒連在一起的東西塗回綠色。
- 小昭也每個方向都真的生成，不左右翻轉。阿胖不用全程睜大眼睛，像小昭那樣自然眨眼就好（主人 2026-10-01）。
- 花費：兩隻貓的「正上」試做 0.4 美元，其餘 8 支 1.6 美元，共 2 美元（API 累計約 60.9 美元）。
- **阿胖坐姿放大 6%**（主人：坐著時他不比小昭大，但他比較重）：spike `af35_sit_scale.py` 以腳為中心放大 sit 定格、`idle_sit`、`lick`，`lie_to_sit`／`sit_to_lie` 在動作中逐漸 1↔1.06；他的撲也一樣放大。

## 4. 程式

| 檔案 | 內容 |
|---|---|
| `src/shared/toy.ts` | 純函式：羽毛相對於頭的方向（5 區）、距離（注意／搆得到）、在不在動、失去興趣的計時 |
| `src/main/toy-window.ts` | 逗貓棒視窗：透明、最上層、只有棒子和羽毛可以抓、拖曳移動 |
| `src/toy/toy.html／.ts／.css`、`src/main/preload-toy.ts` | 畫棒子、線、羽毛，擺錘物理，回報羽毛的螢幕位置和速度 |
| `src/main/toys.ts` | 逗貓棒總管：拿出／收起，每隻貓的注意狀態，告訴貓咪坐起來或往哪撲 |
| `src/pet/pet.ts` | 收到「盯著」就坐起來並暫停自動行動；收到「撲」就在坐著時插播那支撲的影片（速度 ±10%）；「不玩了」就恢復 |
| 寵物包 `toy` 欄位 | `{ pose: "sit", swats: { left, upLeft, up, upRight, right }, left, right }`，跟 `pounce`、`fight` 同一種寫法 |
| `tools/convert_*.py` | 加上撲的片段和 `toy`；也補上這一輪直接寫進 pack.json 的欄位（`lines.back`、`lines.time`、`alert`、`card`），否則重轉會被洗掉 |

- 貓咪視窗高度不變。
- 測試：單元（方向分區、距離、在不在動、失去興趣）；端到端（測試用的貓加上 `toy` 和假影片，拿出逗貓棒、模擬羽毛位置和速度，貓咪坐起來、往對的方向撲、停下 5 秒後恢復）。
