# 毛孩桌寵（暫名）設計文件

- 日期：2026-09-27
- 狀態：待審
- 範圍：子專案 A「桌面程式」。子專案 B「寵物包製作工具」另有設計文件，兩者以本文件第 5 節的寵物包格式銜接。

## 1. 目標

在自己的 Windows 電腦上，讓幾隻固定的貓咪（第一隻是小昭）住在桌面上。牠們用 AI 生成的真實影片呈現，有自己的個性，會自己換姿勢、會回應點擊，也會提醒你喝水和休息。

### 1.1 第一版要做

| 項目 | 內容 |
|---|---|
| 貓咪 | 程式內建幾隻固定貓咪，第一隻是小昭 |
| 動作 | 每隻貓的基本姿勢和互相切換，加上 2 個專屬互動（小昭：紙箱翻肚、藍色抱枕） |
| 互動 | 點牠（依個性回應）、拖曳（只在允許的姿勢）、右鍵選單下指令 |
| 個性 | 每隻貓自己的台詞、每個姿勢待多久、最愛去哪裡 |
| 多隻 | 可以同時放好幾隻在桌面上，各自獨立 |
| 健康提醒 | 喝水、伸展、休息眼睛三種定時提醒，由貓咪用泡泡告訴你 |
| 日常 | 系統列圖示、控制面板、開機自動啟動、記住每隻貓的位置和大小 |

### 1.2 不做（第一版）

- 上架任何商店、Mac 版、程式簽署
- 讓別人自己做寵物；帳號、後端、付款
- 把戲（擊掌、拜託…）、游標玩具、技能養成和徽章：需要額外影片，之後補影片即可加上（見第 12 節）
- 晚上想睡覺的作息、貓咪之間的互動、多螢幕（只用主螢幕）

## 2. 名詞

| 名詞 | 意思 |
|---|---|
| 姿勢（pose） | 貓咪可以停留的狀態，例如「趴著」「紙箱翻肚」 |
| 過渡姿勢 | 只是路過、不會停留的姿勢，例如「趴著，旁邊出現紙箱」 |
| 待機片段 | 同一個姿勢頭尾相接、可以一直循環的短片 |
| 轉場片段 | 從姿勢 A 變成姿勢 B 的影片 |
| 淡入淡出邊 | 不需要影片的轉換：畫面上只有道具出現或消失，用 0.5 秒交叉淡化 |
| 姿勢圖 | 所有姿勢和它們之間的轉換（片段或淡入淡出） |
| 寵物包 | 一隻貓的資料夾：設定檔、透明影片、頭像 |

## 3. 架構

技術：Electron（TypeScript），只支援 Windows 10/11。安裝檔用 electron-builder 產生（NSIS），只給自己安裝。

```
主程式（main process，看不到畫面）
 ├─ 寵物包載入與檢查
 ├─ 設定讀寫（%APPDATA%\desktop-pet\settings.json）
 ├─ 貓咪視窗管理（每隻貓一個）
 ├─ 系統列圖示和選單
 ├─ 健康提醒計時器
 └─ 開機自動啟動
        │ IPC
        ├─ 貓咪視窗（renderer，每隻貓一個）
        │    播放引擎、行為引擎、點擊／拖曳、泡泡
        └─ 控制面板（renderer，需要時才打開）
```

### 3.1 程式碼結構

```
desktop-pet/
  src/
    shared/   寵物包格式、姿勢圖、行為引擎、提醒排程（純邏輯，不碰 Electron，方便測試）
    main/     主程式：視窗、系統列、設定、提醒、寵物包載入
    pet/      貓咪視窗：影片播放、互動、泡泡
    panel/    控制面板
  packs/      內建寵物包（每隻貓一個資料夾）
  tests/      單元測試、整合測試、測試用的小寵物包
  docs/
```

原則：所有「決定下一步做什麼」的邏輯都放在 `shared/`，是純函式、亂數由外部傳入。畫面和 Electron 的部分只負責執行決定。

## 4. 貓咪視窗

- 無邊框、透明、永遠在最上層、不顯示在工作列。
- 視窗大小等於這隻貓的影片畫面在目前大小下的尺寸（例如小昭在「中」大約 782×440）。
- 預設貼在主螢幕工作區域的底部，也就是工作列上方。
- 設定檔只記錄水平位置，垂直方向每次都落回工作列上方。
- 讓一隻貓出現時，如果牠的位置和已經在桌面上的貓重疊（身體中心相距小於兩隻貓身體寬度的一半），就往右挪到不重疊的地方；右邊放不下就往左找。整個工作區域都放不下時，允許重疊。

### 4.1 滑鼠穿透

- 視窗平常設成「滑鼠穿透」，但仍然接收滑鼠移動事件（`setIgnoreMouseEvents(true, { forward: true })`）。
- 滑鼠移動時，檢查游標底下那一格影片畫面的透明度（把目前畫面縮小畫到 160×90 的 canvas 上取樣）。
  - 不透明，代表滑鼠在貓咪或道具上：通知主程式關閉穿透，這時才能點擊或拖曳。
  - 透明：恢復穿透，點擊會落到後面的程式。

### 4.2 拖曳和落下

- 只有姿勢設定 `draggable: true` 時可以拖（小昭只有「趴著」可以）。其他姿勢按住拖動時，只會冒出 `noDrag` 台詞。
- 拖曳時由 renderer 計算新的視窗位置，透過 IPC 請主程式移動視窗，每秒 60 次。
- 身體依滑鼠速度輕輕擺動（淡定個性：擺動幅度小、速度慢）。
- 放開後以重力落下，碰到工作列時稍微壓扁再彈回，然後記住新的水平位置。

### 4.3 大小

- 三段：小（0.75）、中（1.0）、大（1.3），以寵物包的 `displayHeight` 為「中」的基準。
- 控制面板可以在 0.6 到 1.5 之間微調。
- 視窗大小會跟著變，並自動確保整隻貓都在螢幕內。

## 5. 寵物包格式

每隻貓一個資料夾：

```
packs/xiaozhao/
  pack.json
  portrait.png          控制面板用的頭像，正方形
  clips/*.webm          VP9 + 透明通道，960×540，24fps
```

影片尺寸定為 960×540：貓咪在螢幕上最多約 440px 高，用不到更高的解析度。這樣內顯解碼比較省力。

### 5.1 pack.json

以小昭為例（節錄：只列出「趴著」和紙箱相關的姿勢、片段和轉換，藍色抱枕的部分寫法相同，這裡省略）：

```json
{
  "schemaVersion": 1,
  "id": "xiaozhao",
  "name": "小昭",
  "personality": "淡定、愛翻肚、最愛紙箱",
  "portrait": "portrait.png",
  "frame": { "aspect": 1.7778, "displayHeight": 440 },
  "start": "lie",
  "poses": {
    "lie":      { "label": "趴著", "idle": ["idle_lie"], "ground": 0.906, "centerX": 0.30, "head": 0.41,
                  "shadow": true, "draggable": true, "stay": 0.7, "autoWeight": 1 },
    "lieBox":   { "label": "（紙箱出現）", "transient": true, "ground": 0.906, "centerX": 0.30, "head": 0.41, "shadow": true },
    "boxBelly": { "label": "紙箱翻肚", "idle": ["box_idle"], "ground": 0.906, "centerX": 0.75, "head": 0.42,
                  "shadow": false, "draggable": false, "stay": 0.85, "autoWeight": 1.4 }
  },
  "clips": {
    "idle_lie":  { "file": "clips/idle_lie.webm" },
    "box_enter": { "file": "clips/box_enter.webm" },
    "box_exit":  { "file": "clips/box_exit.webm", "rate": 0.8 }
  },
  "edges": [
    { "from": "lie",      "to": "lieBox",   "fade": 0.5 },
    { "from": "lieBox",   "to": "boxBelly", "clip": "box_enter" },
    { "from": "boxBelly", "to": "lieBox",   "clip": "box_exit" },
    { "from": "lieBox",   "to": "lie",      "fade": 0.5 }
  ],
  "lines": {
    "greet": ["……喵。"],
    "click": { "default": ["……", "嗯。", "喵。", "（慢慢眨眼）"], "boxBelly": ["……zzz", "……（不為所動）"] },
    "drag": ["……隨便你", "（液態貓）"],
    "noDrag": ["……（不想動）"],
    "command": { "lie": "……嗯。", "boxBelly": "（盯——紙箱）" },
    "reminders": {
      "water":   { "default": "……該喝水了。", "boxBelly": "……（睡夢中）去喝水。" },
      "stretch": { "default": "……起來動一動。" },
      "eyes":    { "default": "……眼睛休息一下。" }
    }
  },
  "clickHeart": true,
  "commands": [ { "label": "趴著", "pose": "lie" }, { "label": "紙箱翻肚", "pose": "boxBelly" }, { "label": "藍色抱枕", "pose": "pillow" } ]
}
```

欄位說明：

- `frame.aspect`：影片寬高比。`displayHeight`：「中」大小時視窗的高度（px）。
- 姿勢欄位：
  - `ground`：地面線在畫面中的高度比例，貓咪或道具的底部要對齊工作列。
  - `centerX`：身體中心的水平比例，影子和泡泡用。
  - `head`：頭頂高於地面線多少（畫面高度的比例），泡泡用。
  - `stay`：待機片段播完後，繼續待著的機率。
  - `autoWeight`：自己決定換姿勢時，選到這個姿勢的權重。
  - `transient`：過渡姿勢，沒有待機片段，程式會繼續往下走，不會停在這裡。
- 轉換（`edges`）：每一條是影片片段（`clip`）或淡入淡出（`fade`，秒數）其中之一。
- 片段的 `rate`：播放速度，預設 1。
- 台詞：每一類都可以用 `default` 加上依姿勢覆寫；陣列代表隨機挑一句。

### 5.2 寵物包檢查（程式啟動時）

以下任何一項不通過，這隻貓會被標為「無法使用」，並在控制面板顯示原因；其他貓照常運作：

1. `pack.json` 符合格式，`schemaVersion` 是支援的版本。
2. `edges` 和姿勢的 `idle` 裡提到的每個片段都有定義，對應的檔案也存在。
3. `start` 是非過渡姿勢，而且至少有一個待機片段。
4. 每個非過渡姿勢都有待機片段；過渡姿勢至少有一條往外的轉換。
5. 從 `start` 出發走得到每個姿勢，而且每個姿勢都走得回 `start`。
6. `commands` 指到的都是非過渡姿勢。

## 6. 行為引擎（`shared/behavior`）

引擎只負責「決定下一段要播什麼」，輸出一串步驟：播某個片段、或淡入淡出到某個姿勢。

1. **永遠在播一段影片**：片段播完的那一刻才決定下一段，所以畫面不會跳。
2. **下指令時**：用姿勢圖找最短路徑（廣度優先搜尋），從目前這段播完後的姿勢走到目標，再接一段目標姿勢的待機片段。
   - 會先取代原本排好但還沒播的步驟。
   - 貓咪會立刻冒出 `command` 台詞，表示聽到了。
   - 目前這段播完才開始走，最多等一段片段的長度（小昭最長的「走出紙箱」放慢後約 9 秒）。
3. **自己行動時**（控制面板或右鍵選單的「自動行動」開著）：
   - 待機片段播完後，以機率 `stay` 繼續待著，隨機挑一段這個姿勢的待機片段。
   - 否則依 `autoWeight` 從其他非過渡姿勢挑一個目標，走過去。
4. **自動行動關閉時**：只在目前姿勢循環待機，只聽指令。
5. **播放器的執行規則**：
   - 片段之間用 0.12 秒交叉淡化，蓋掉細小的接縫。
   - 淡入淡出邊用 `fade` 指定的秒數，先淡到下一段的第一格再開始播。
   - 同一段待機片段接自己時不淡化。
   - 任何時候只保留一段影片可見。
6. **影片播不出來時**：把那條轉換標為不能用，重新找路；找不到路就留在原姿勢循環待機。

## 7. 點擊、泡泡、選單

- **點擊**（按下後沒有拖動）：依目前姿勢從 `lines.click` 挑一句。醒著、且 `clickHeart` 為 true 時，冒一顆小愛心。沒有跳躍之類的動作。
- **泡泡**：出現在 `centerX` 和 `head` 算出的頭頂位置，2.2 秒後消失，會跟著貓咪移動。
- **右鍵選單**（系統原生選單）：
  - 這隻貓的指令（`commands`）
  - 自動行動（勾選）
  - 大小（小／中／大）
  - 放回工作列
  - 先收起來
- **系統列**：
  - 左鍵：打開控制面板
  - 右鍵：打開控制面板、每隻貓出現或隱藏的勾選、全部收起來、提醒暫停 1 小時、開機自動啟動、結束

## 8. 控制面板

三個分頁：

- **我的貓咪**：每隻貓一張卡片，包含頭像、名字、個性、目前姿勢、「出現在桌面」、「自動行動」、大小滑桿、指令按鈕。無法使用的貓顯示原因。
- **健康提醒**：
  - 喝水、伸展、休息眼睛三種提醒，各自可以設成「關閉」或每 30／45／60／90 分鐘一次。
  - 「同時跳出 Windows 通知」開關。
  - 「試一次提醒」按鈕。
- **設定**：開機自動啟動、把所有貓放回工作列、版本資訊。

第一次執行時自動打開控制面板，小昭直接出現在桌面上。之後開機只在背景執行。

## 9. 健康提醒（`shared/reminders` + 主程式）

- 每種提醒各自計時。時間到了，主程式挑一隻正在桌面上的貓（依設定裡的順序挑第一隻），請牠顯示提醒泡泡。台詞用 `lines.reminders[類型]`，依牠目前的姿勢挑。
- 泡泡有「喝好了」和「10 分鐘後」兩個按鈕：
  - 按「喝好了」，或 15 秒沒理會：該提醒重新開始計時。
  - 按「10 分鐘後」：10 分鐘後再提醒一次。
- 開啟 Windows 通知時同時跳通知。沒有任何貓在桌面上時，只跳通知。
- 「提醒暫停 1 小時」會暫停所有提醒，時間到自動恢復。
- 電腦睡眠或鎖定時不累計時間：從睡眠醒來、或解鎖後，重新開始計時。

## 10. 設定檔

位置：`%APPDATA%\desktop-pet\settings.json`

```json
{
  "version": 1,
  "firstRunDone": true,
  "autoStart": true,
  "pets": {
    "xiaozhao": { "visible": true, "scale": 1.0, "auto": true, "x": 0.62 }
  },
  "petOrder": ["xiaozhao"],
  "reminders": { "water": 45, "stretch": 60, "eyes": 0, "notify": true, "pausedUntil": null }
}
```

- `x`：貓咪身體中心在主螢幕工作區域中的水平比例。用比例而不是 px，換解析度時也不會跑出畫面。
- 提醒的數字是間隔分鐘，0 代表關閉。
- 讀取時遇到缺少的欄位就補預設值。檔案壞掉時備份成 `settings.bad.json`，改用預設值，並在控制面板提示一次。
- 寫入時先寫暫存檔再改名，避免寫到一半當機把設定弄壞。

## 11. 錯誤處理

| 狀況 | 處理 |
|---|---|
| 寵物包檢查不通過 | 那隻貓標為無法使用、面板顯示原因，其他貓照常 |
| 某段影片載入或播放失敗 | 行為引擎避開那條轉換（第 6 節第 6 點），寫入記錄檔 |
| 設定檔壞掉 | 備份後改用預設值（第 10 節） |
| 貓咪位置在螢幕外（換了螢幕或解析度） | 載入時自動拉回工作區域內 |
| 貓咪視窗當掉 | 主程式重新開這隻貓的視窗，最多重試 3 次 |

記錄檔：`%APPDATA%\desktop-pet\logs\`，保留最近 5 個。

## 12. 之後可以加的功能

設計上預留的擴充方式（第一版不做）：

- **把戲、健康提醒專屬動作**：在寵物包加上新的姿勢和片段，指令清單和提醒台詞指過去即可，程式不用改。
- **技能養成**：在寵物包的指令加上「要練習幾次才學會」，由設定檔記錄進度。行為引擎不用改，只需要多一個面板分頁。
- **游標玩具**：需要能左右鏡像的撲擊片段，加上一個追蹤游標的新互動模組。
- **作息**：讓 `stay` 和 `autoWeight` 可以依時段不同，例如晚上提高睡覺的權重。

## 13. 測試

- **單元測試（Vitest，`shared/` 全部）**：
  - 姿勢圖找路（包含淡入淡出邊、避開壞掉的轉換）
  - 行為引擎的決定（亂數用固定種子）
  - 寵物包檢查的每一條規則（各有一個會失敗的測試包）
  - 提醒排程（假時鐘：到期、延後、暫停、睡眠醒來）
  - 設定讀寫（缺欄位、壞檔、原子寫入）
- **整合測試（Playwright 的 Electron 模式）**：用一個測試寵物包（ffmpeg 產生的幾段 1 秒色塊透明影片），確認：
  - 啟動後貓咪視窗出現
  - 下指令後片段依正確順序播放
  - 右鍵選單和系統列選單的項目正確
- **手動檢查清單（每次發佈前）**：
  - 透明處點擊會穿透
  - 拖曳和落下
  - 多隻貓不會重疊
  - 提醒泡泡的兩個按鈕
  - 開機自動啟動
  - 全螢幕影片或遊戲時貓咪不會卡住畫面
  - 放著跑一小時，CPU 和記憶體沒有持續上升

## 14. 效能目標

在目前這台筆電（Intel Iris Xe）上：

- 一隻貓：CPU 平均 5% 以下，記憶體 250 MB 以下
- 三隻貓：CPU 平均 12% 以下

做法：影片固定 960×540；預載目前姿勢會用到的片段，其他片段第一次用到時才載入；螢幕鎖定或關閉時暫停播放，解鎖後從原姿勢繼續。

## 15. 與子專案 B 的介面

### A.4 製作規則（飼主的回饋，交給子專案 B 遵守）

- 毛色：偏冷的深藍灰色，帶一點淡紫。以白光照片量到的顏色為準（Lab 約 L 38、a 3、b −1），不要參考沙發那幾張黃光照片。
- 胸口是深灰色，肚子只比背部稍淺一點（不是米白色）。眼睛上方的毛比較稀疏（淡淡的禿眉），眼睛是深琥珀橘色。
- 醒著的時候，包括走路、爬上爬下，眼神都要半瞇、放鬆，不能睜大眼睛或看起來吃驚。
- 動作要慢、懶洋洋的，符合淡定的個性。
- 每段的提示詞只提到這段會出現的道具。例如抱枕的片段裡提到紙箱，AI 就會把紙箱畫出來。
