# 提醒事項、備忘錄、離開時睡著、依時間改變行為 設計文件

- 日期：2026-10-01
- 狀態：已和主人逐段確認
- 版本：0.6.0

## 1. 目標

三個功能一起出：

1. **離開時睡著**：電腦一段時間沒人用，貓咪去睡；有人用了，貓咪坐起來。
2. **提醒事項（小昭）＋備忘錄（阿胖）**：兩張可以在貓咪頭上直接編輯的卡片。
3. **依時間改變行為**：早安、吃飯、下班、週五、該睡了，午後和深夜比較愛睡。

1 和 3 已先做好（分支 away-and-time），本文件也記下它們因為 2 而要改的地方。

## 2. 離開時睡著

- 每 2 秒問一次系統「多久沒有鍵盤或滑鼠輸入」（Electron `powerMonitor.getSystemIdleTime()`，Windows、Mac 都可以）。
- 超過設定的分鐘（面板「設定」：關閉／3／5／10，預設 5）就算離開。
- 離開時：每隻貓**隨機**去一個睡著的姿勢（`asleep: true`、不是 transient、不是 brief）：小昭是睡覺或紙箱翻肚，阿胖是睡覺或側躺。已經睡著的不動。自動行動暫停、不打鬧；喝水、伸展、護眼提醒不送，回來後重新計時。
- 回來時（有輸入）：因為離開而去睡的貓，醒來到寵物包的 `alert` 姿勢（**坐起來**，小昭、阿胖都是 `sit`），沒有 `alert` 就回 `start`。其中一隻說「你回來了」（`lines.back`；當天第一次見面改說早安）。坐好以後再依勾選跳出卡片（第 4 節）。
- 測試機也會閒置，所以測試用 `DESKTOP_PET_FAKE_IDLE` 蓋掉真實的閒置時間。

## 3. 依時間改變行為

| 時間 | 事件 |
|---|---|
| 當天第一次出現（開 app 或回到電腦），平日 5:00–11:00 | 早安 `morning` |
| 週末第一次出現（5:00 以後） | `weekend`「假日還在工作？」 |
| 12:00 | `lunch` |
| 週五 17:00 | `friday` |
| 平日 18:00 | `offWork` |
| 0:00–4:30 每 30 分 | `bedtime` |
| 13:00–14:00 | 睡著的姿勢被選中的機會 ×3 |
| 22:00–5:00 | 睡著的姿勢 ×3，每個姿勢待的時間 ×2 |

- 一天從 5:00 算起。兩隻貓都在時只讓隨機一隻說。離開時、護眼休息時不說。電腦睡了錯過的時間點不補說。
- 台詞放在寵物包 `lines.time.<事件>`，回來的台詞在 `lines.back`。

## 4. 提醒事項和備忘錄

### 4.1 誰拿哪張卡

寵物包新欄位 `card`：小昭 `"todo"`（提醒事項），阿胖 `"memo"`（備忘錄）。沒有任何寵物包拿某張卡，那張卡就不存在（測試用的貓預設沒有卡）。

卡片出現在**主人頭上**；主人不在桌面上，就出現在被操作的那隻貓頭上（自動跳出時則是桌面上的第一隻貓）；一隻貓都沒有就不跳卡（到點的提醒仍有系統通知）。

### 4.2 叫出和收起

- 游標在貓咪身上**往上捲**：打開這隻貓自己的卡（有卡才有）。**往下捲**：收起這隻貓頭上的卡。
- 貓咪右鍵選單多「提醒事項」「備忘錄」兩項（有那張卡才出現）。
- 卡片上的 ✕、標題列上往下捲、按 Esc：收起。
- 自己叫出來的卡片會拿到鍵盤焦點（備忘錄直接可以打字）；自動跳出和到點的卡片不搶焦點。

### 4.3 自動跳出

每張卡各一組設定（面板新分頁「提醒與備忘」）：

| 時機 | 備忘錄預設 | 提醒清單預設 |
|---|---|---|
| 開啟打工貓貓（含開機自動啟動），等貓咪走到位置 | ☑ | ☑ |
| 電腦從睡眠或休眠醒來 | ☑ | ☑ |
| 解除螢幕鎖定 | ☑ | ☑ |
| 離開電腦後回來（貓咪坐起來以後） | ☑ | ☐ |
| 每天固定時間（時、分分開選，分以 10 分鐘為一格，可關閉） | 09:00 | 09:00 |

- 30 秒內同一張卡的自動跳出只算一次（睡眠醒來、解鎖、回來常常一起發生）。
- 離開電腦時遇到每天的時間，先記著，回來時再跳。
- 自動跳出的卡片 30 秒沒碰就收起；滑鼠在卡片上或卡片有焦點時不收。

### 4.4 備忘錄卡（樣式 C：阿胖貓耳便條）

- 寬 240 px。藍灰色（#8A96A8）標題列「阿胖的備忘錄」，上方兩個貓耳，右上 ✕。
- 下面一整塊自由打字；停止打字 0.5 秒自動存。字多卡片變高，約 10 行後在卡片內捲動。

### 4.5 提醒事項卡（樣式 C：小昭貓耳清單）

- 寬 280 px。深灰色（#5B5C60）標題列「小昭的提醒事項」，貓耳，琥珀色（#BA7517）勾選框和 ＋。
- 清單依時間排序：勾選框、時間、內容，重複的另標「每天」或「平日」。滑鼠移上去出現垃圾桶。點內容可以直接改字（Enter 或離開輸入框就存，Esc 取消）。
- 新增區兩行：「時」(00–23)「分」(00、10…50)「一次／每天／平日」；內容輸入框和 ＋（Enter 也可以）。
- 勾選：一次的劃掉變淡，隔天 5:00 自動刪掉；每天、平日的今天劃掉，隔天 5:00 恢復。
- 到點的那一則琥珀色底，旁邊「完成」「10 分鐘後」；錯過的另標「錯過」。
- 約 8 則以上在卡片內捲動。

### 4.6 到點

- 每 15 秒檢查一次。
  - 一次：建立或改時間時算出「下一個這個時間」（今天還沒到就是今天，否則明天），到了就提醒。過期很久沒提醒到的（電腦關著）也照樣提醒，標「錯過」。
  - 每天：每天那個時間；平日：週一到週五那個時間。今天（從 5:00 起）錯過的開機後補提醒，標「錯過」。
  - 按「10 分鐘後」：10 分鐘後再提醒一次，清單上的時間不變。
- 提醒時：拿卡的貓（小昭，不在就換第一隻在桌面上的貓）**坐起來看著你**（`alert` 姿勢；你離開時不叫醒），頭上跳出提醒卡（不搶焦點），到點的亮起；同時系統通知「15:00 開會」，點通知會打開卡片。
- 卡片一直留著，直到每一則到點的都按了「完成」或「10 分鐘後」；最後一則按完，3 秒後收起（滑鼠在卡片上就等移開），貓咪回到平常的行動。
- 好幾則同時到點就一起亮。

### 4.7 卡片的位置

- 卡片是獨立的小視窗（可以打字、可以拿焦點），永遠在最上層，不出現在工作列。
- 貓咪視窗回報頭的位置（螢幕座標）：每段影片開始時、拖曳中、拖曳結束後；走進來或拖曳時算「沒站穩」。
- 卡片水平置中在頭上，卡片底邊在頭上方 80 px（中間留給對話泡泡），超出工作區就往內推。拖曳貓咪時卡片跟著走。
- 卡片需要等貓咪站穩才出現（例如開 app 時等牠走到位置）。

### 4.8 資料

- 設定（跳出時機）放在 `settings.json` 的 `cards`。
- 備忘錄文字和提醒清單放在同一個資料夾的 `notes.json`（先寫暫存檔再改名）：

```json
{ "version": 1, "memo": "要買貓砂", "todos": [
  { "id": "k3x9", "text": "開會", "hour": 15, "minute": 0, "repeat": "once",
    "at": 1790000000000, "doneDay": null, "firedAt": null, "snoozeUntil": null } ] }
```

  `at` 只有「一次」有；`doneDay` 是打勾那天（從 5:00 算的日期）；`firedAt` 是已經提醒過的那次時間點；`snoozeUntil` 是「10 分鐘後」。
- 檔案壞掉時改名成 `notes.bad.json`，從空的開始，並記在紀錄裡。
- 不同電腦之間不同步。

## 5. 程式結構

| 檔案 | 內容 |

## 6. 測試

- 單元：`todo.ts`（一次／每天／平日、錯過、延後、打勾、隔天清理、跨 5:00）、`notes.ts`、`cards` 設定、寵物包 `card`／`alert` 欄位。
- 端到端（測試用的貓另外複製一份並加上 `card`）：往上捲打開卡、打字存進 `notes.json`、在卡上新增提醒、到點跳出亮起並坐起來、按完成後收起、往下捲收起、開 app 時自動跳出、30 秒內只跳一次。
