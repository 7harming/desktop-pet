- 狀態：已和主人逐段確認
- 範圍：小昭頭上的第三種卡片「今晚吃什麼」，轉盤選晚餐；菜單可以自己改；轉的時候貓咪坐起來往上拍

## 2. 卡片

- **外觀**：跟提醒事項同一套（`card.css`）：小昭的灰色標題列 `--fur: #5b5c60`、貓耳、琥珀色重點 `--accent: #ba7517`。標題寫「今晚吃什麼」。整頁以 186 px 排版，再用 CSS `zoom: 1.3` 放大（字、轉盤、貓耳、按鈕一起放大），視窗寬 242 px。
  - 不用 `webContents.setZoomFactor`：Chromium 的縮放是同一個網址來源共用的，三張卡片都載入 `card.html`，會連提醒事項一起放大。
- **轉盤畫面**：轉盤（灰白相間的格子、上方琥珀色指針、中間小圓點）、結果一行（「今晚吃：牛肉麵」）、左下「改菜單」、右下「轉一下」。
  - 從按下「轉一下」到轉盤停下（包括等貓咪拍的那段），「轉一下」和「改菜單」暫時不能按；停下來就能再轉，次數不限。
  - 轉動約 3.2 秒，先快後慢，轉 5 圈以上停在主程式選好的那一格。
  - **昨天的菜**：格子變淡（`#D3D1C7`），字變灰，格子裡多寫「昨天」；指針不會停在那裡。隔天恢復成一般格子。
- **改菜單畫面**（卡片翻面）：一樣菜一列；點菜名就地改（Enter 或離開輸入框存，Esc 取消，跟提醒事項一樣）；垃圾桶刪除；最下面輸入新菜，Enter 或「＋」加入；按「完成」翻回轉盤。改了就存，不用另外按儲存。
  - 規則：最少 2 樣、最多 12 樣；每樣 1～6 個字（去掉前後空白，以字元算）；不能重複。違反時卡片上顯示一行紅字（「至少要留兩樣」「最多 12 樣」「最多 6 個字」「已經有了」「先輸入菜色」），不送出。主程式也再檢查一次。
- **預設菜單**：便當、牛肉麵、滷肉飯、水餃、拉麵、火鍋、咖哩飯、炒飯。
- 轉到一半關掉卡片（✕、Esc、滾輪往下、自己收起來）：這次不算，不記錄，貓咪不說話，回到原本的樣子。

## 3. 打開與跳出

- **只給小昭**（2026-10-18 主人改）：轉盤只出現在小昭頭上。只有小昭的右鍵選單在「提醒事項」「備忘錄」旁多一個「今晚吃什麼」，阿胖的沒有。小昭不在桌上時（被收起來），控制面板的「現在打開」或自己跳出會先叫她走出來，她到位坐定後轉盤才出現。（提醒事項、備忘錄照舊：自己的貓不在，就出現在按右鍵的那隻貓頭上。）
- **滾輪**：小昭身上往上還是開提醒事項（寵物包的第一張卡片）；往下收起她頭上所有卡片，轉盤也一起。
- **控制面板**「提醒與備忘」分頁多一張「小昭的晚餐轉盤」，選項跟其他卡片一樣（開機、喚醒、解鎖、回到電腦時、每天幾點；時間以 10 分鐘為單位），有「現在打開」。預設：`{ start: false, resume: false, unlock: false, back: false, daily: 17*60+30 }`。
- 17:30 主人不在電腦前：照現有規則等主人回來、貓坐起來才跳出。小昭不在桌上就先叫她出來。
- 自己跳出的卡片 30 秒沒碰就收起來（滑鼠在上面或有焦點時不算）；手動打開的不會自己收。
- **好幾張卡片**：會疊到的卡片排成一排，互相貼著，以它們中心的平均位置為中心，不超出工作區。例如小昭頭上同時有提醒事項和轉盤，兩張並排；三張都開就三張一排。

## 4. 貓咪的動作

1. 卡片送出「轉一下」→ 主程式先選好結果（第 5 節），再叫卡片下面那隻貓（卡片的 `petId`）「拍轉盤」。
2. 貓咪：躺著就先坐起來（寵物包 `toy.pose`，小昭和阿胖都是 `sit`；正在播的待機動畫直接打斷，馬上開始起身，2026-10-18 用真的貓試過：等待機播完要多等 4～7 秒），坐好後插播 `toy.swats.up`（逗貓棒的往上拍，約 1.4 秒）。播到爪子最高的那一刻回報「拍到了」：那一刻記在寵物包 `toy.upPeak`（0～1，片段長度的比例），從各自的 `swat_up` 影格量出來（貓的輪廓最高的那一格），寫進轉換程式；寵物包沒寫就用 0.45。
3. 主程式收到「拍到了」才叫卡片開始轉；轉完卡片回報，主程式記下結果，叫貓咪說話。
4. 說話：寵物包 `lines.dinner`（每句裡的 `{dish}` 換成菜名），隨機挑一句，泡泡照現有規則躲開卡片。寵物包沒寫就用「今晚吃{dish}！」。
   - 小昭：「……今晚吃{dish}。」「……就{dish}吧。」「……{dish}，可以。」（2026-10-18 主人選她平常的冷靜口氣）
   - 阿胖沒有轉盤，也沒有轉盤台詞。
5. 說完約 5 秒，貓咪回到原本的樣子（`pack.start`）；這期間再轉就繼續坐著再拍。正在玩逗貓棒就留在 `toy.pose`；有提醒事項到點（attend）就留在 `alert`。
6. **貓咪不方便動**：立刻回報「不拍」，卡片馬上自己轉，轉完照樣說出答案：
   - 睡著的姿勢（`isAsleep`：睡覺、紙箱翻肚）、主人不在（away）、正在走進／走出、被拖曳、打鬧中、在喝水或伸懶腰這類短暫姿勢（brief）
   - 寵物包沒有 `toy`，或坐起來／往上拍的空間不夠（靠右邊，`fitsAt`）
   - 保險：主程式送出「拍轉盤」後 12 秒還沒收到回報，卡片也先轉（原本寫 4 秒，但真的貓起身比較慢：小昭坐起來 5.0 秒，按下到拍到約 5.5 秒；阿胖起身要 7.2 秒以上，雖然他沒有轉盤，保險仍留得夠長）。
7. 正在玩逗貓棒時本來就坐著，照樣拍。
8. 不用新影片，**不花 API 的錢**。

## 5. 選菜與「昨天的菜」

- 「日」用本地日期（跟提醒事項同一個換日函式）。
- 記錄：`last`（最近一次轉到的菜和那天的日期）、`prev`（`last` 之前那一天的最後一個）。轉完在 D 日記錄時：`last` 不是 D 日 → `prev = last`；然後 `last = { day: D, dish }`。同一天重轉只更新 `last`。
- 今天要避開的菜：今天是 D 日，昨天是 D−1。`last.day === D` 時看 `prev`，否則看 `last`；那筆的日期是 D−1 才避開它的菜。
- 選菜：從菜單裡去掉要避開的那一樣（它不在菜單裡就不去掉），平均隨機挑一樣。菜單只有 2 樣時就一定是另一樣。
- 卡片的狀態帶「昨天的菜」，轉盤據此把那一格變淡。

## 6. 資料

- `notes.json`（`userData`，跟提醒事項、備忘錄同一個檔，不跨電腦同步）多一個欄位：
  ```json
  "dinner": { "items": ["便當", "牛肉麵"], "last": { "day": "2026-10-17", "dish": "便當" }, "prev": null }
  ```
- 讀檔（`normalizeNotes`）：沒有 `dinner` 或格式不對就用預設菜單；不合規則的菜（空的、超過 6 個字、重複）丟掉；超過 12 樣只留前 12；剩不到 2 樣就用預設菜單；`last`／`prev` 格式不對就當成沒有。

## 8. 測試

- **單元**：
  - `dinner.ts`：菜名規則（空、6 個字、7 個字、重複、前後空白）；要避開的菜（昨天、前天、今天已經轉過、跨月跨年）；選菜不會選到要避開的那一樣、2 樣菜時一定是另一樣、避開的菜不在菜單裡時照常選；記錄結果時 `prev`／`last` 的變化。
  - `notes.ts`：舊檔沒有 `dinner` → 預設菜單；壞掉的菜被丟掉；剩不到 2 樣 → 預設菜單。
  - `settings.ts`：`cards.dinner` 的預設值、正規化。
  - `pack.ts`：`card` 一張或一串都合法，不認識的種類報錯；`lines.dinner`。
  - `pet-geometry.ts`：三張一排、同一隻貓頭上兩張、沒有疊到就不動、靠右邊時不超出工作區、寬度不一樣的卡片（186 和 242）。
  - `menus.ts`：右鍵選單有「今晚吃什麼」。
- **端到端**（只用 `npm run test:e2e:hidden`，在隱藏桌面跑，不在主人的螢幕上）：從右鍵選單／面板打開轉盤，寬 242、提醒事項仍是 186，兩張並排不重疊；按「轉一下」→ 測試貓坐起來往上拍 → 轉盤停在主程式選的那一格 → 泡泡說出那道菜；改菜單（新增、改名、刪除、規則的紅字）後重開還在；昨天的菜那一格變淡、轉不到；貓咪不方便動時轉盤自己轉；轉到一半關掉不記錄。
