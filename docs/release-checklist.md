# 上線前檢查清單

每次產生新的安裝檔後，在自己的電腦上逐項確認：

## 安裝與開啟
- [ ] 打包前已設定密碼（點兩下專案資料夾的「設定安裝密碼.cmd」；在 PowerShell 裡請用 `npm.cmd`，`npm` 會被執行原則擋下）
- [ ] 執行安裝檔（未簽署，Windows 會出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」）
- [ ] 安裝程式第一頁要求密碼；輸入錯誤會提示再試一次，正確才進到下一頁
- [ ] 桌面和開始選單都有「打工貓貓」捷徑
- [ ] 安裝完成後小昭從螢幕左側走進來，走到右下方趴下，控制面板自動打開
- [ ] 把小昭收起來、再點一次桌面捷徑：小昭又走出來（程式開著時再點一次，也會打開控制面板）
- [ ] 收起最後一隻貓時，右下角跳出「怎麼叫牠回來」的提示
- [ ] 重新開機後小昭自動出現（開機自動啟動）；在設定分頁關掉後重開機，就不再自動出現

## 出場與退場
- [ ] 走路是抬頭側面往前走，頭全程維持側面、不會微微轉向鏡頭；腳踩在地上不打滑，一段接一段看不出接縫
- [ ] 「先收起來」：小昭（若不是趴著，先回到趴著）起身往左走，走出螢幕左邊才消失
- [ ] 系統列「結束」：小昭先走出去，程式才關掉

## 互動
- [ ] 透明的地方點擊會穿透到後面的程式
- [ ] 點小昭出現台詞；睡覺和紙箱翻肚時不冒愛心
- [ ] 任何姿勢都能拖曳（走路進出時除外），放開落回工作列；貼著小昭的邊緣也點得到
- [ ] 右鍵選單的每一項都有作用
- [ ] 右鍵選單和控制面板都有「喝水」「向左撲」「向右撲」；不是趴著時按撲，會先回到趴著再撲
- [ ] 趴著時連點兩下：點貓身體左半邊往左撲、右半邊往右撲，撲完回原位趴好；撲的途中、或不是趴著時連點，只會出現一般台詞
- [ ] 系統列圖示左鍵打開控制面板、右鍵選單每一項都有作用

## 待機動作與位置
- [ ] 控制面板「待機時會做」只勾坐下：小昭自己只會在趴著和坐下之間；最後一個勾取消不掉
- [ ] 「待機時會做」有「伸懶腰」「喝水」「向左撲」「向右撲」可勾；勾著時偶爾會自己做
- [ ] 取消勾選紙箱和抱枕後，小昭可以拖到螢幕最右邊貼著邊緣；勾回來時會讓出右邊給紙箱／抱枕
- [ ] 設定分頁「自動行動時，多久換一個動作」選約 30 秒：貓在一個姿勢大約待 30 秒才換（15、60 秒同理）；喝水、伸懶腰做完就回來，不受影響
- [ ] 大小滑桿最小可以拉到 0.4 倍；右鍵選單的「小」是 0.5 倍
- [ ] 貓走進來或走出去的途中改大小：整隻貓等比例變大變小，不會被壓扁或拉長

## 多隻貓（有第二隻貓的寵物包時）
- [ ] 控制面板和系統列裡小昭排第一個（系統列圖示是小昭）；應用程式和捷徑的圖示是小昭和阿胖的頭像並排
- [ ] 讓兩隻都出現，不會疊在一起
- [ ] 各自的位置和大小在重開程式後都還在
- [ ] 同樣的大小設定下，阿胖比小昭略大一點；阿胖走路、側躺時跟趴著時一樣大，不會突然變大
- [ ] 兩隻都在桌面上時，喝水／伸展提醒兩隻一起出現；按其中一隻的按鈕，另一隻的泡泡也收掉
- [ ] 兩隻都在時按「試一次休息」：兩隻大貓一起走進來，各趴在螢幕一半的中間；時間到一起走出去，再各自走回桌面

## 阿胖
- [ ] 勾選「出現在桌面」：阿胖從左邊走進來趴下，之後休息時是母雞蹲（兩隻前腳收起來）
- [ ] 右鍵選單和控制面板有「母雞蹲」「坐下」「睡覺」「側躺」「踏踏」「洗臉」「舔嘴巴」，每一項都會做；踏踏、洗臉、舔嘴巴做完回到原本的姿勢
- [ ] 踏踏是兩隻前腳左右輪流慢慢踩，約 15 秒；側躺的樣子像照片 IMG_1847
- [ ] 往左走出去時是阿胖自己的向左走（看得到左後腿的灰斑），尾巴豎著、頭保持側面，一步接一步看不出接縫
- [ ] 往右走進來時頭保持側面，接縫看不出來
- [ ] 在右下角側躺時，尾巴不會被螢幕右邊切掉
- [ ] 只讓阿胖出現時按「試一次休息」：大阿胖走進來趴下、再走出去
- [ ] 控制面板裡阿胖的頭貼是正面的臉
- [ ] 喝水提醒（「試一次提醒」）時阿胖舔舔嘴巴；伸展提醒時翻身側躺伸展、再翻回來

## 兩隻貓打鬧
- [ ] 把小昭和阿胖拖到一起，按控制面板的「讓牠們打鬧一下」：兩隻同時起身拱背面對面、坐下互相出拳、再趴回去（約 6 秒），各說一句話，然後照常活動
- [ ] 兩隻離很遠時按那個按鈕：面板顯示「兩隻貓離太遠了」，貓不會動
- [ ] 其中一隻在睡覺時按：面板顯示「牠們現在正忙」
- [ ] 「兩隻貓靠近時偶爾打鬧」打勾、兩隻放在一起：偶爾會自己打鬧（最多每 10 分鐘一次）；取消打勾後不會自己打

## 健康提醒
- [ ] 「試一次提醒」出現泡泡和按鈕；按鈕點得到
- [ ] 「10 分鐘後」會在 10 分鐘後再提醒；「好了」或 15 秒沒理會，照設定的間隔重新計時
- [ ] 喝水提醒（或「試一次提醒」）：米色水碗在小昭右邊淡入，小昭起身走過去低頭喝水，喝一輪以上後走回原位趴下，水碗淡出；關掉自動行為時也會自己走回來
- [ ] 喝水循環重播時看不出接縫；水碗在走過去、喝水、走回來之間不會跳動
- [ ] 伸展提醒：小昭起身側面伸懶腰、維持一下再趴回原位；右鍵選單「伸懶腰」和偶爾自己伸也一樣，伸完一定回到原本的姿勢
- [ ] 伸懶腰、喝完水走回來時，尾巴碰到畫面邊緣的地方是柔和淡出，不是一刀切齊
- [ ] 「試一次休息」：小昭走出左邊 → 畫面變暗、大小昭從左邊走進來趴在中間 → 右上角倒數 30 秒 → 大小昭走出去 → 小昭從左邊走回右下方
- [ ] 休息中按「跳過」，大小昭馬上起身離開
- [ ] 鎖定螢幕再解鎖，提醒重新計時、小昭繼續動

## 其他
- [ ] 看全螢幕影片、玩全螢幕遊戲時小昭不會卡住畫面
- [ ] 全螢幕看影片時點小昭，小昭不會被影片蓋掉消失
- [ ] 改螢幕解析度後，小昭回到工作列上方
- [ ] 效能：用 `DESKTOP_PET_METRICS=1` 啟動，放著一小時，記錄檔裡 CPU 平均 5% 以下、記憶體（括號外的私有記憶體）250 MB 以下，而且沒有持續上升
  （2026-09-27 實測：待機 CPU 約 5%，其中影片解碼約 3%、畫面合成約 1.6%，走路時約 8.5%；私有記憶體約 400 MB，其中 Electron 本身約 186 MB。CPU 在門檻邊緣，記憶體的 250 MB 目標目前達不到）

## Mac 版（測試版）
- [ ] 在 GitHub 的 Actions 分頁執行「Mac test build」，下載 mac-dmg 解壓出 .dmg
- [ ] 打開 .dmg，把「打工貓貓」拖到「應用程式」；第一次打開若被擋，到「系統設定 → 隱私權與安全性」按「強制打開」
- [ ] 小昭從螢幕左邊走進來，停在 Dock 上方；上方選單列有貓咪圖示
- [ ] 收起小昭後點 Dock 上的「打工貓貓」，小昭又走出來
- [ ] 切換桌面空間、開全螢幕 App 時小昭還在
- [ ] 注意：Mac 的安裝檔沒有安裝前密碼（這是 Windows 安裝程式才有的功能）

## 離開、時間、提醒事項與備忘錄（0.6.0）
- [ ] 5 分鐘不碰電腦：兩隻貓都去睡（小昭睡覺或紙箱翻肚、阿胖睡覺或側躺）；動一下滑鼠：坐起來，其中一隻說「你回來了」（當天第一次是早安）
- [ ] 面板「設定」的「離開電腦多久」選關閉：怎麼放都不會睡
- [ ] 12:00、18:00（平日）、週五 17:00、半夜每 30 分：只有一隻貓說話
- [ ] 游標在小昭身上往上捲：頭上出現「小昭的提醒事項」；往下捲收起；阿胖往上捲是「阿胖的備忘錄」
- [ ] 右鍵選單有「提醒事項」「備忘錄」；只有一隻貓在時，另一張卡出現在牠頭上
- [ ] 備忘錄打字後關掉再打開，內容還在；重開 app 也還在
- [ ] 新增「時：分」「一次／每天／平日」的提醒；到點時小昭坐起來、卡片亮起、跳系統通知；「完成」打勾，「10 分鐘後」十分鐘後再來；按完 3 秒後卡片收起、小昭趴回去
- [ ] 開機、睡眠醒來、解鎖、離開回來、每天固定時間：依「提醒與備忘」分頁的勾選自動跳出，30 秒沒碰自己收起；幾件事一起發生只跳一次
- [ ] 拖著貓咪走，卡片跟著；貓咪在螢幕邊緣時卡片不會超出螢幕
